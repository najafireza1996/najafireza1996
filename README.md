## About

I'm a Backend Lead at **SarvNeoBank**, where I own the **Ledger**: the module that has to be right every time, because every balance, transfer and statement depends on it. I build it with Domain-Driven Design, and I care most about consistency, auditability and boundaries that hold up as the system grows.

Recently I led the move from a **Modular Monolith** to **microservices**, with **Kafka** for event-driven communication and **Ocelot** as the gateway.

## Current focus

- Ledger domain modeling with DDD: aggregates, domain events, clear bounded contexts
- Event-driven architecture on Kafka, and keeping data consistent across services
- Messaging and workflows with Wolverine
- Performance and correctness on SQL Server with EF Core
